# Code of Conduct

OpenTile aims to be a respectful, collaborative project. Be constructive, assume good intent, and avoid harassment, discrimination, or personal attacks.

If you experience or witness unacceptable behavior, report it privately to [matheuseabra@protonmail.com](mailto:matheuseabra@protonmail.com). Reports will be handled confidentially and may result in moderation actions, including removal from project spaces.
