# Keyboard shortcuts

## Level editing

- `B`: brush mode
- `M`: rectangular selection mode
- `E`: eraser mode
- `Option/Alt + click`: tile dropper
- `Control` held: show the keyboard tile cursor
- `Command/Ctrl + arrows`: move the active level selection or keyboard cursor
- `Shift + arrows`: resize a level rectangle selection
- `Command/Ctrl + C`: copy
- `Command/Ctrl + X`: cut
- `Command/Ctrl + V`: paste
- `Command/Ctrl + Z`: undo
- `Command/Ctrl + Y`: redo
- `Space + mouse drag`: pan the main canvas area
- `Mouse wheel over the level`: zoom the level grid
- `Mouse wheel over the tileset`: zoom the tileset grid

## Debug and levels

- `F3`: toggle debug overlays
- `Option/Alt + L`: hide/show the layers panel
